# i18n Conventions

## Translation keys

- All user-facing strings must use `const { t } = useI18n()` — never hardcode strings in templates
- Keys must use **snake_case at every level**:
  ```ts
  // ✅
  t('trip_filters.sort_by')
  t('profile.personal_info.first_name')
  // ❌
  t('tripFilters.sortBy')
  ```

## Locale files

Add new keys to **hr.json and en.json** only (`it` and `de` will be filled in later):
```
i18n/locales/hr.json  ← always update
i18n/locales/en.json  ← always update
i18n/locales/it.json  ← skip for now
i18n/locales/de.json  ← skip for now
```

## Route localization

```ts
defineI18nRoute({
  paths: {
    hr: '/putovanja',
    en: '/trips',
  },
})
```

## Localized links

```ts
const localePath = useLocalePath()
// <TLink :to="localePath('route-name')">
```
